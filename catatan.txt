BEARER TOKEN :
autHeader (req.headers.authorization): Amplop dari client berisi teks "Bearer <TOKEN>".
autHeader && ... (Rem Pengaman): Cek apakah amplopnya ada. Kalau kosong (undefined), langsung berhenti agar .split() tidak bikin server crash.
.split(' ')[1] (Pemotong Kata): Memecah teks berdasarkan spasi menjadi ["Bearer", "<TOKEN>"], lalu mengambil indeks ke-1 ("<TOKEN>" saja).
if (!token) (Penjaga Pintu): Kalau amplop kosong atau formatnya salah (tidak ada spasi), token otomatis undefined $\rightarrow$ langsung tolak dengan status 401.

res.status(200).json(...): Sukses biasa (contoh: login berhasil, ambil data GET, update data). Khusus kasus 200, menulis res.json(...) sebenarnya sama saja hasilnya, tapi menulis res.status(200).json(...) bikin kode lebih konsisten dan jelas terbaca.
res.status(201).json(...): Sukses membuat data baru (contoh: register akun baru, tambah produk).
res.status(400).json(...): Input user tidak lengkap atau formatnya salah.
res.status(401).json(...): Gagal autentikasi (email/password salah saat login, atau token JWT tidak valid).
res.status(409).json(...): Data bentrok/duplikat (contoh: email sudah terdaftar).
res.status(500).json(...): Terjadi error tak terduga di server/database (di dalam blok catch)
